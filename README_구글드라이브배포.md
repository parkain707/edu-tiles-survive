## ☁️ 2. 구글 드라이브(Google Drive)에 올려 배포하기

구글 드라이브를 통해 학생들에게 배포하는 방법은 크게 두 가지가 있습니다.

### 방법 A. 구글 드라이브 파일 공유 (학생 다운로드용 - 권장)
학교 컴퓨터실이나 학생 개인 기기에서 다운로드하여 오프라인으로 실행할 때 가장 안전하고 확실합니다.

1. `edu-tiles-survive` 폴더 전체를 ZIP 파일(`EduTiles_6-2사회.zip`)로 압축합니다.
2. [Google Drive](https://drive.google.com)에 로그인한 뒤, 압축한 ZIP 파일을 업로드합니다.
3. 업로드된 파일 우클릭 ➔ **[공유]** ➔ **[링크가 있는 모든 사용자에게 공개(뷰어)]** 설정.
4. 링크를 복사하여 구글 클래스룸(Google Classroom)이나 e학습터, 위두랑 등에 게시합니다.
5. **학생 실행법**:
   - 링크를 통해 다운로드 후 압축 풀기 ➔ `index.html` 더블 클릭! (인터넷 연결 없이도 작동)

---

### 방법 B. DriveToWeb (구글 드라이브를 웹사이트로 실시간 호스팅)
구글 드라이브에 올린 HTML 파일을 학생들이 다운로드하지 않고 **웹 링크 클릭만으로 바로 웹상에서 플레이**할 수 있게 해주는 무료 서비스입니다.

1. 구글 드라이브 내에 새 폴더를 만들고 이름을 `edutiles`로 지정합니다.
2. 폴더 속성에서 **[공유] ➔ [링크가 있는 모든 사용자 - 뷰어]**로 설정합니다.
3. 폴더 안에 게임의 모든 구성 파일(`index.html`, `css/`, `js/`)을 업로드합니다.
4. 브라우저에서 [https://drv.tw](https://drv.tw) 접속 후 **[Host on Google Drive]** 클릭.
5. 구글 계정 로그인 및 권한을 승인하면, 구글 드라이브 폴더를 인식하여 **웹 링크(URL)**를 즉시 생성해 줍니다.
6. 생성된 링크를 학생들에게 전달하면 설치 없이 웹에서 바로 게임을 즐길 수 있습니다.

---

### 방법 C. GitHub Pages / Netlify 무료 원클릭 웹 배포 (초스피드 대안)
구글 드라이브 외에 가장 깔끔한 단축 웹 주소를 제공하고 싶으시다면:
- **GitHub Pages**: 저장소 생성 후 `index.html` 및 리소스 업로드 ➔ Settings - Pages 활성화 (1분 소요).
- **Netlify Drop** ([app.netlify.com/drop](https://app.netlify.com/drop)): `edu-tiles-survive` 폴더를 웹 브라우저 창에 드래그 앤 드롭하기만 하면 즉시 전 세계 접속 가능한 `https://xxx.netlify.app` 링크가 발급됩니다.
